# Month 01 — AWS 인프라 기초 구축 (2026.03)

## 작업 개요

하이브리드 CWPP 프로젝트의 첫 단계.
AWS EKS 기반 Multi-AZ 구성으로 VPC 네트워크 인프라와 IAM Role, EKS 클러스터를 구축했다.

자동화 도구 없이 AWS 콘솔 기반 수동 구성으로 진행했으며,
각 리소스의 역할과 설계 의도를 명확히 이해하는 것을 목표로 했다.

<br>

### 1. VPC 생성

프로젝트의 모든 리소스(EKS, RDS)가 들어갈 독립적인 네트워크 환경 구성.

|---|---|
| VPC ID | vpc-0bd51d7cee0a72897 |
| CIDR | 10.0.0.0/16 (65,536개 IP) |
| Status | Available |

---

### 2. Subnet 4개 생성

각 AZ마다 Public / Private 2개씩 총 4개 서브넷으로 구성.
Private Subnet은 인터넷 완전 차단으로 DB 외부 공격 경로를 원천 차단한다.

**AZ-A (ap-northeast-2a)**

| Subnet Name | CIDR | Public IP 자동할당 | 용도 |
|---|---|---|---|
| cwpp-public-subnet-a | 10.0.1.0/24 | O | Worker Node 1, ALB |
| cwpp-private-subnet-a | 10.0.2.0/24 | X | 거래소 DB, CWPP DB, Redis |

**AZ-B (ap-northeast-2b)**

| Subnet Name | CIDR | Public IP 자동할당 | 용도 |
|---|---|---|---|
| cwpp-public-subnet-b | 10.0.3.0/24 | O | Worker Node 2, ALB |
| cwpp-private-subnet-b | 10.0.4.0/24 | X | RDS Standby Failover |

---

### 6. IAM Role 생성

**EKS Node Role**

| Policy | 용도 |
|---|---|
